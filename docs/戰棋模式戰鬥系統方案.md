# JOSE 戰棋模式戰鬥系統方案

> 狀態：已決定採用。本文件取代原本「上下排固定站位」的戰鬥呈現方向。

## 1. 戰鬥核心決策

JOSE 的幻獸戰鬥改為方格戰棋，而非傳統的我方全體回合、敵方全體回合。

採用方格而非六角格，理由如下：

- PixiJS 2D 呈現、技能範圍與手機觸控較容易實作。
- 近戰位移、遠程投射與障礙物遮擋的規則更直覺。
- 現有戰鬥舞台可直接改造成方格地圖。

## 2. 第一版戰場

使用 `6 欄 × 5 列` 的小型戰場。

```text
敵方部署區：第 1 至 2 列
爭奪區：第 3 列
我方部署區：第 4 至 5 列
```

- 每格只能放一隻幻獸或一個障礙物。
- 第一版採 3 對 2、3 對 3 與首領戰。
- 戰場可有熔岩格、灰燼格與岩柱障礙物。

## 3. 行動順序

每一隻幻獸依速度進入行動條，流程如下：

```text
速度決定下一位行動者
→ 選擇移動格
→ 選擇技能
→ 顯示可攻擊目標或技能範圍
→ 執行動畫與特效
→ 結算狀態、冷卻與地形
→ 下一位行動者
```

每個單位有：

- 移動點。
- 行動點。
- 技能冷卻。
- 格子座標。
- 朝向。
- 異常狀態與增益效果。

## 4. 攻擊距離與位移

技能必須標示 `attackStyle`：

| 類型 | 規則 | 動畫 |
| --- | --- | --- |
| melee | 必須在目標相鄰格 | 跑到目標前方，命中後回位或留在前線。 |
| ranged | 可隔格攻擊 | 原地施法，投射物飛過格子。 |
| support | 目標為己方 | 原地施放，特效落在己方格。 |
| area | 指定中心格與範圍 | 顯示範圍格後釋放大範圍特效。 |

只有 `melee` 技能觸發跑到目標格旁的位移。遠程、治療、輔助不得錯誤前衝。

## 5. 幻獸定位

| 定位 | 戰棋職責 |
| --- | --- |
| 攻擊型 | 突進、斬殺、突破後排。 |
| 防禦型 | 擋路、護衛、嘲諷、反擊。 |
| 輔助型 | 加速、增傷、推拉、淨化。 |
| 治療型 | 治療、護盾、復活、範圍支援。 |
| 控制型 | 冰凍、束縛、擊退、封技。 |
| 全能型 | 補位、半輸出、半支援。 |

## 6. 幻獸數值

每隻幻獸資料均須補齊：

- 生命：存活與承傷。
- 力量：物理與近戰傷害。
- 魔力：元素、遠程、治療傷害或效果。
- 防衛：物理減傷。
- 速度：行動條與移動能力。
- 暴擊、效果命中、韌性：戰鬥深化參數。

## 7. 地形與元素

熔火裂谷第一版地形：

| 地形 | 效果 |
| --- | --- |
| 熔岩格 | 回合結束受火焰傷害，火系獲得增傷。 |
| 灰燼格 | 降低命中或提供伏擊效果。 |
| 岩柱 | 阻擋移動與直線遠程攻擊。 |

後續森林加入藤蔓、草地；海洋加入水池、冰面與潮流。

## 8. 特效標準

每個行動至少包含：

```text
蓄力 → 位移或投射 → 命中 → hit-stop → 受擊閃白 → 傷害字 → 狀態效果 → 回位
```

特效分為通用特效庫與幻獸專屬終結技。所有幻獸都必須依近戰、遠程、範圍、治療與控制類型取得相對應的戰鬥特效。

## 9. 實作階段

1. 建立 6 × 5 格子戰場與單位座標。
2. 將現有戰鬥改為依速度單位回合。
3. 實作移動範圍、近戰相鄰判斷、遠程距離判斷。
4. 實作技能範圍、地形、障礙物與狀態結算。
5. 先完成火狐、炎獅、熔岩蟹、赤羽鳥、炎靈獸五隻測試角色。
6. 擴充火系十隻，再擴充森林與海洋。

## 10. 與養成系統的關係

進化、等級、力量、魔力、防衛、速度、定位與技能會直接影響戰棋玩法，而不再只是數值變化。

例如：

- 炎獅進化後可增加突進距離與擊退能力。
- 熔岩蟹進化後可守住更多相鄰格並保護隊友。
- 火狐最終型態可提升遠程狐火範圍並獲得九尾突進終結技。
- 赤羽鳥可跨越岩柱攻擊後排。
