# 《幻獸戰棋》世界觀與主線劇情核心基準（Story Canon）

版本：v1.0｜更新：2026-07-19  
原始完整設定：[`《幻獸戰棋》世界觀與主線劇情設計基準.txt`](./《幻獸戰棋》世界觀與主線劇情設計基準.txt)

本文件是後續劇情、關卡、角色、Boss、幻獸、任務、掉落與視覺敘事開發的**最高故事依據**。若既有遊戲資料與本文件衝突，新增內容必須依本 Canon 對齊；不得為了單一關卡方便而改動文明順序或核心真相。

## 核心命題

玩家是能與所有融合核心共鳴的「晶核共鳴者」。冒險從森林幻獸異變開始，歷經龍族、機械、天界、魔界，最終面對虛空與世界重置循環。

始源晶核（Origin Core）在遠古「大崩解」後散為融合核心（Fusion Core）。不同文明對核心有不同詮釋：生命、血脈、數據、秩序、力量與錯誤。玩家代表「選擇與融合」，不是單純消滅敵人，而是決定世界是否繼續依循歸零循環。

## 不可違反的世界規則

1. 所有主要故事均須逐步回扣「始源晶核／融合核心」。
2. 幻獸＝生命與自然；龍族＝血脈與守護；機械＝效率與永恆；天界＝秩序與控制；魔界＝自由與生存；虛空＝歸零與循環；玩家＝選擇與融合。
3. 各文明不可被寫成絕對邪惡，必須有可理解的生存理由與價值觀。
4. 每章 Boss 必須有背景、戰鬥理由與戰後資訊；不可只是關卡終點怪物。
5. 前期必須埋下後期文明伏筆；每 10 章形成一個完整篇章高潮。
6. 第 50 章完成第一部主線，但保留第 51 章後的延伸空間。

## 主線規格

- 長期目標：50 大章。
- 每章：10 個普通關 + 1 個章節 Boss + 4 個 HARD 特別關。
- 主線進度固定顯示為「第 X 章｜0/11」；11 = 10 普通關 + 1 Boss，HARD 不計入主線進度。
- 解鎖規則：完成 10 個普通關並擊敗章節 Boss 才可開啟下一章。
- HARD 用途：菁英討伐、限回合挑戰、文明衝突事件、隱藏 Boss；優先補充角色背景、Boss 過去、文明歷史與未來伏筆。

## 後續四篇章章節與 Boss 索引

### 虛空終焉（41–50）

時空亂流／時界吞噬獸、破碎世界／世界殘骸巨神、倒轉時之城／逆時鐘王、平行幻境／鏡像玩家與鏡像幻獸軍團、文明墓場／文明收割者、虛空前哨／虛空觀測者、無限迴廊／終焉守門人、始源核心／始源核心守護者、世界之外／虛空神使、創世終焉／Origin・始源終焉之主。

第 50 章 Origin 必有五型態：自然／幻獸、龍族／元素、機械／數據、天界／魔界、虛空／始源。

## 融合核心：劇情與系統連結

融合核心既是劇情主物件，也是養成素材。核心類型為自然、龍魂、數據、聖光、深淵、虛空、始源。來源依序為普通敵人碎片、菁英主要來源、章節 Boss 高階核心、HARD 稀有核心與篇章 Boss 文明級核心。

後續系統與劇情必須對齊篇章解鎖：數據核心開啟機械化／機甲龍；聖光核心開啟聖獸／神聖龍；深淵核心開啟魔獸／魔龍；多文明核心結合始源核心才可開啟終極融合形態。

## 每章開發檢核表

新增或改寫章節前，至少確認：

- [ ] 章節位置符合五大篇章時間線與該文明主題。
- [ ] 開場、關卡中事件、Boss 前演出、Boss 後結果能形成一個小型敘事閉環。
- [ ] Boss 有明確動機、技能與地形設計能反映其文明／背景。
- [ ] 至少一個普通關或 HARD 關承接前章事件，或埋下後章伏筆。
- [ ] 融合核心掉落、角色加入、圖鑑描述與新養成系統都能回扣本章文明。
- [ ] 不以「絕對善／惡」簡化任何文明。
- [ ] UI 的章節簡述、Boss 情報、立繪、地圖主色與劇情一致。

## 開發決策優先序

1. Canon 與時間線正確。
2. 角色動機、Boss 目的與文明價值觀一致。
3. 關卡機制、敵人、掉落和視覺服務敘事。
4. 再處理數值與重複遊玩設計。

任何未在本文件定義的 NPC、幻獸、支線、Boss 或新系統，都可以擴寫；但不得推翻上述世界起源、篇章順序、最終真相與玩家的最終選擇。
