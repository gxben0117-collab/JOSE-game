# JOSE 戰鬥地圖改善方案

更新日期：2026-07-17  
適用版本：V0.12

## 改善目標

戰場必須同時做到「看得清楚、找得到單位、移動不暈、地圖像一個完整場景」。本輪先解決尺寸、鏡頭與零碎地形三個核心問題，再逐步加入更精緻的地圖美術。

## 第一階段：已完成

- 戰場由 30×30 縮為 20×20，共 400 格，降低無效走路距離。
- 格子與幻獸戰旗預設放大為原基準的 1.5 倍，縮放按鈕可切換 1.5×／2×。
- 玩家點選棋盤上的我方或敵方單位、或點選隊伍卡時，鏡頭平滑置中。
- 單位移動、攻擊、反擊、敵方回合與自動戰鬥期間不再驅動鏡頭，觀看者的視角保持穩定。
- 我方改為左下 6×6 部署區；敵軍從右側多個隊形錨點配置，維持左右交戰方向。
- 元素地形由逐格隨機灑點改成 3～5 格半徑的連續區域。
- 障礙物由孤立散點改成三組短牆／岩群，形成通道、掩體與繞行選擇。

## 第二階段：地圖邊界美術

- 為熔岩、森林、水域製作中心、直邊、外角、內角共 16 種自動拼接圖塊。
- 相鄰同類地形共用邊界遮罩，消除每格仍可辨認的方形接縫。
- 障礙物改為 2×2、1×3、L 型等組合素材，並補陰影方向，讓岩牆、古木與遺跡像同一組物件。
- 每個主題限制主色三種、重點色一種，避免背景搶過單位與技能特效。

## 第三階段：手工戰術骨架

建立至少六種可重用的 20×20 地圖骨架，關卡種子只負責裝飾變化，不重新打散主要路線：

1. 開闊平原：中央少量掩體，適合新手與遠程教學。
2. 雙線推進：上下兩條主路，中間可穿越，適合分隊包抄。
3. 熔岩峽谷：狹窄通道與高風險捷徑，強調擊退。
4. 中央遺跡：中央大型掩體，迫使隊伍從兩側接戰。
5. 河川渡口：兩座橋與一處淺灘，強調移動與控制。
6. 首領競技場：中央完整戰區、周邊可躲避區，確保大型首領不被障礙卡住。

## 第四階段：規則與品質驗證

- 所有我方部署格到主要敵軍區至少存在兩條可行路徑。
- 大型 2×2、3×3 單位具有足夠通道，不會出生後卡死。
- 遠程視線遮蔽必須可從美術上辨認，不使用看似可穿越卻實際阻擋的物件。
- 小地圖同步顯示地形區、障礙群、敵我單位與目前視窗框。
- 桌機與手機各檢查部署、點選置中、拖曳、縮放、移動、攻擊、敵方回合與自動戰鬥。

## 驗收標準

- 點任一可見單位後，單位會落在視窗中央附近。
- 點移動或攻擊後，視窗捲動位置保持不變。
- 20×20 共 400 格，部署區為 6×6。
- 預設格子縮放值為 1.5，角色戰旗隨格子同步放大。
- 絕大多數元素地形格至少與一個同類地形格相鄰，不再出現滿場散點。
- 三組障礙物形成可理解的短牆／掩體，同時保留通往敵方的可行路線。
