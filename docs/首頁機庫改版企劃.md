# JOSE 幻獸戰棋｜首頁機庫改版企劃

更新日期：2026-07-19
狀態：需求已確認，尚未開始介面實作。

## 核心方向

首頁採用「方案 A：機庫作戰中心」與「方案 C：首頁主獸延伸制」的組合。

- 最上方固定顯示資源：水晶、金幣、戰術徽章、元素精華、融合核心。
- 最下方固定主導航：`⚔️ 關卡`、`🐉 幻獸編隊`、`⬆️ 強化`、`📖 圖鑑`、`🎰 召喚`、`🗼 無限塔`、`🌍 探索`。
- 左側固定生活功能：`📋 每日任務`、`🏡 幻獸之家`、`🏪 商店`、`🎒 背包`。
- 中央是大型「首頁展示幻獸」立繪與元素機庫背景；右側放目前進度、推薦行動與重點提示。
- 其他頁面共用機庫視覺語言，並顯示目前展示幻獸的小型投影；強化、圖鑑與編隊頁則由該頁選中的幻獸擔任中央主角。

## 首頁展示幻獸：首批五隻

玩家只能從已擁有的幻獸中設定首頁展示幻獸。首批預設提供五種元素代表；實作時以實際資料庫中的對應角色 ID 綁定。

1. 赤炎神龍：預設展示角色；熔岩機庫、火焰粒子與紅橙光效。
2. 森林神獸：樹海溫室、藤蔓與綠色投影。
3. 深海神獸：深海艙、水波、氣泡與藍色投影。
4. 光屬核心幻獸：聖域機庫、金白光環與浮動符文。
5. 暗屬核心幻獸：裂隙觀測站、紫黑星塵與能量裂縫。

### 設定規則

- 預設為赤炎神龍。
- 點擊中央立繪或「更換展示幻獸」按鈕，開啟已擁有幻獸清單。
- 清單支援名稱、元素、定位、體型與稀有度篩選。
- 選定後保存至本機進度；下次進入遊戲沿用設定。
- 圖鑑可預覽未擁有幻獸，但未擁有者不可設為首頁展示。
- 提供「恢復預設（赤炎神龍）」與「跟隨目前隊長」兩種設定。

# 路線一：完整願景版

包含首頁主幻獸五選一，以及目前累積的 37 項改善構想。此路線適合作為長期產品藍圖，應拆成多個版本逐批實作。

## 1～9：首頁核心體驗

1. 主幻獸點擊互動：播放短待機／攻擊動作與專屬台詞。
2. 展示幻獸收藏解鎖：取得指定幻獸後自動加入展示名單。
3. 角色展示台：顯示名稱、元素、星級、等級、戰力與強化捷徑。
4. 今日重點卡：最多三件重要行動，例如任務、收成、推薦關卡。
5. 首頁快捷出擊：直接前往最近可挑戰的主線關卡。
6. 元素背景變化：背景、粒子與主色依展示幻獸元素切換。
7. 隊長同步選項：展示幻獸可固定，或自動跟隨目前隊長。
8. 收斂紅點：只提示真正可領取、可收成或可使用的內容。
9. 幻獸檔案室：全螢幕查看立繪、技能、台詞、元素、成長與動作。

## 10～17：陪伴感與主城擴充

10. 首頁主幻獸依早晚切換光線與環境效果。
11. 幻獸心情與狀態反應，例如勝利興奮、閒置打盹、可強化提醒。
12. 每日首次登入短台詞與今日行動摘要。
13. 主城背景解鎖：旗艦機庫、森林溫室、深海艙、天空神殿、裂隙觀測站。
14. 目前編隊的其他幻獸以淡化陪襯方式出現在主幻獸後方。
15. 隊伍戰力、未配置隊伍與可升星幻獸的溫和提醒。
16. 收藏成就牆：圖鑑率、最高無限塔、主線進度與最愛幻獸。
17. 降低動態效果設定；低耗電或小型裝置自動減少粒子。

## 18～27：便利性、儀式感與活動

18. 展示幻獸收藏冊：保留展示歷程、使用次數與首次獲得日期。
19. 主幻獸一鍵設為隊長或派駐幻獸之家。
20. 背景音樂、音效與幻獸語音分別調整音量。
21. 首頁天氣／章節連動：隨目前戰役章節變換窗外景象。
22. 活動入口只在有活動時顯示，避免固定空按鈕。
23. 可重看新手導覽與各功能說明。
24. 資源點擊直達：金幣到商店、水晶到召喚、精華到強化、核心到融合。
25. 戰鬥後回首頁回饋：主幻獸迎接、顯示本次收穫及下一步養成提示。
26. 首頁截圖模式：隱藏 UI，只保留立繪、背景、隊伍與名稱。
27. 每月首頁主題：僅替換背景、粒子、主色與 BGM，不改操作結構。

## 28～37：長期留存與個人化

28. 幻獸好感度：以戰鬥、互動、派駐解鎖展示姿勢與專屬台詞。
29. 隊長羈絆：展示主幻獸與編隊成員的元素／種族連線效果。
30. 生日、獲得週年、進化與升星紀念事件。
31. 角色口吻留言板：用幻獸口吻提供可做事項提醒。
32. 最愛幻獸輪播：可選一至五隻輪播，或固定一隻。
33. 戰報終端：顯示最近三戰、最高傷害、守護塔狀態等摘要。
34. 玩家目標釘選：例如升到五星、通關某章或登塔指定層數。
35. 每日一次小型隨機事件與額外資源回饋。
36. 展示幻獸外觀切換：進化型態、未來造型與節慶皮膚。
37. 主幻獸專屬或可選的首頁 BGM。

# 路線二：第一版可交付範圍

此路線是建議優先執行的版本，先建立高品質首頁骨架，避免一次塞入全部 37 項功能。

## 必做項目

1. 首頁主幻獸五選一。
2. 方案 A＋C 的機庫首頁版面。
3. 完成上列 1～9 項首頁核心體驗。
4. 追加四項高效益功能：資源點擊直達、章節背景連動、戰鬥後回首頁回饋、首頁截圖模式。

## 第一版頁面配置

| 區域 | 內容 |
| --- | --- |
| 上方資源列 | 五種資源數量；點擊可直接進入對應功能。 |
| 左側生活列 | 每日任務、幻獸之家、商店、背包；只在可操作時出現紅點。 |
| 中央展示台 | 主幻獸大型立繪、元素背景、名字、星級、等級、戰力、互動與更換按鈕。 |
| 右側指揮面板 | 繼續遠征、目前關卡、今日重點、隊伍戰力提示。 |
| 底部主導航 | 關卡、編隊、強化、圖鑑、召喚、無限塔、探索。 |

## 第一版其他頁面規則

- 關卡：機庫戰術地圖，右側顯示敵軍、掉落與出擊。
- 編隊：中央展示隊長與隊伍立繪，右側為候補與篩選。
- 強化：被選幻獸成為中央主角，兩側放能力、升星、融合與進化操作。
- 圖鑑：機庫收藏牆；點選後開啟大型立繪與資料。
- 召喚：中央水晶投影台，保留逐張揭示、立繪、台詞與跳過按鈕。
- 無限塔：守護塔與波次情報為主視覺；沿用十波防衛玩法。
- 探索：以區域星圖／節點圖作為入口。

## 介面與技術原則

- **統一橫向遊玩畫布**：桌機與 iPad 均以 iPad 橫向全畫面作為唯一主版型，不另外製作直向縮小版。
- 桌機與 iPad：完整三欄結構（左側功能／中央主視覺／右側指揮），所有主要頁面與彈窗沿用同一套機庫材質、資訊層級與全高畫布。
- 窄螢幕直向開啟時：顯示「請將裝置轉為橫向遊玩」提示；不壓縮地圖、幻獸立繪或戰術操作面板。
- 玩家資料繼續存於 `localStorage`；展示幻獸設定需與既有存檔安全合併。
- 既有立繪、四方向動作、召喚台詞與元素色彩資料應優先重用，不重新製作重複資產。

## 建議實作順序

1. 擴充進度資料：展示幻獸 ID、展示模式與背景選擇。
2. 重做首頁殼層、上方資源列、左側生活列與底部主導航。
3. 加入中央展示台與五隻幻獸選擇器。
4. 接上關卡、強化、圖鑑、召喚等既有入口。
5. 完成 1～9 項核心改善與四項追加功能。
6. 對 iPad、手機與桌機進行視覺／操作回歸測試後上線。

## 尚待使用者確認

- 第一版採用「完整願景版」還是「第一版可交付範圍」。
- 五隻展示幻獸要指定實際角色 ID，或由系統依火／森／海／光／暗各挑一隻現有代表角色。
