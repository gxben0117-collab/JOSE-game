# JOSE 幻獸戰棋：程式開發指南

更新日期：2026-07-19

## 環境需求

| 工具 | 版本 | 用途 |
| --- | --- | --- |
| Node.js | 18+ | lint／test／build 腳本 |
| Python | 3.10+ | 本機預覽伺服器、美術管線 |
| Pillow（PIL） | 任意近期版 | `scripts/generate-enemy-art.py` |

> Windows PowerShell 下請用 `npm.cmd`（工作區慣例）。

## 日常指令

```powershell
npm start        # http://127.0.0.1:4173/（Python http.server）
npm run lint     # 所有 JS 語法 + index/tactics.html 資產引用存在性
npm test         # 35 項回歸測試（含 10 場內部遊玩模擬）
npm run build    # 輸出 dist/（自動排除美術原始檔）
```

### 真實瀏覽器煙霧測試

`tactics.js` 內建 autotest 鉤子，適合用 headless 瀏覽器做整場戰鬥驗證：

```powershell
& "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --headless --disable-gpu `
  --virtual-time-budget=120000 --dump-dom `
  "http://127.0.0.1:4173/tactics.html?autotest=1&stage=ember-4"
# 網頁 <title> 會變成 AUTOTEST:WIN|LOSE:R回合數:ERR錯誤數
```

參數：`stage=`（自動解鎖前置關卡）、`party=id1,id2,id3`、`boost=1`（滿融合＋滿進化＋滿技能樹）。

## 程式結構與修改指引

## 故事／關卡開發前置規則

所有故事、章節關卡、Boss、角色加入、HARD 事件、融合核心掉落與文明視覺，開發前必須先閱讀 [`世界觀與主線劇情核心基準.md`](./世界觀與主線劇情核心基準.md)。它是本專案的 Story Canon：五大篇章順序、始源晶核真相與各文明價值觀不得任意改動；完整原始設定保留於同目錄的 `《幻獸戰棋》世界觀與主線劇情設計基準.txt`。

### 想調整「數值平衡」
- 我方幻獸：`js/data/tactical-pets.js`（由 `pets.js` 原始值換算）。
- 敵人數值與技能：`js/data/tactical-enemies.js`。
- 關卡難度：`js/data/tactical-content.js` 各關 `power`；首領血量倍率在 `tactics.js` `clone()`（×1.1）。
- 調完跑 `node scripts/simulate-tactics.mjs` + autotest 驗證勝敗曲線。

### 想加一個「新敵人」
1. `scripts/generate-enemy-art.py` 的 `MINIONS`／`BOSSES` 加一行（來源幻獸＋調色盤），跑 `python scripts/generate-enemy-art.py`。
2. `js/data/tactical-enemies.js` 用 `enemy()` 工廠加資料。
3. `js/data/tactical-content.js` 把 id 放進關卡 `enemies`。
4. `npm test` 會自動驗證圖片存在與資料 schema。

### 想加一種「異常狀態」
1. `tactics.js`：`clone()` 加欄位 → `applyStatus()` 加分支 → `processRoundEffects()`（回合傷害類）或回合翻轉處（行動限制類）→ `unitElement()` 狀態圖示。
2. `css/tactics-battle.css` 加 `.vfx.fx-*` 特效與單位外觀。
3. `TacticalAudio.js` `patterns` 加音效。
4. 技能資料以 `status: 'xxx', statusTurns: n` 掛在任一技能上即可生效。

### 想調整「AI 行為」
`tactics.js` `planFor()` 是唯一的決策入口，`score` 各項加權：
擊殺 +60、殘血集火、範圍每多命中 +12、控場 +14、位置分（地形／脆皮距離）。
改權重後用 `?autotest=1` 對多關卡跑勝率確認沒有退化。

### 想加關卡／地圖
`tactical-content.js`：`maps` 或 `stages` 加項目（`order` 連續、`power` 遞增、首領放 `enemies[0]`），障礙物由 `seed` 自動生成。測試會驗證全部規則。

## 美術管線

- 幻獸三階立繪：`assets/pets/<id>/evolution/stage_{1..3}.png`（由合圖切出，工具 `scripts/cut-evolution-art.py`）。
- 敵人立繪：`assets/enemies/<id>.png`，一律由 `scripts/generate-enemy-art.py` 重生成（灰階重上色＋魔化氣場），不要手改輸出檔。
- 建置時 `-source`、`evolution-sheet`、`_preview`、`sprites/` 不會進 `dist/`。

## 測試策略

| 層級 | 工具 | 涵蓋 |
| --- | --- | --- |
| 資料 schema | `scripts/test.mjs` | 幻獸／敵人／關卡／任務／技能樹完整性 |
| 進度服務 | `scripts/test.mjs`（vm 沙盒） | 存檔、解鎖、融合、任務統計 |
| 引擎特徵 | `scripts/test.mjs`（source regex） | 視線、位移、狀態、部署階段存在 |
| 數值平衡 | `scripts/simulate-tactics.mjs` | 10 場快速模擬、40 回合上限 |
| 端到端 | `?autotest=1` headless | 真實引擎整場戰鬥、console 零錯誤 |

## 版本慣例

- 現行開發資訊集中在 `docs/開發現況與流程.md`；既有逐版日誌已封存至 `不需要的檔案/文件封存_2026-07-19/docs/development-log/`。
- 舊檔案不刪除，移入 `不需要的檔案/`（保持可追溯性）。
