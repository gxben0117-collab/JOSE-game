# V0.13.1 戰前主城捲動與出擊列修正

日期：2026-07-17

## 問題

橫向桌機版為了讓戰鬥棋盤固定在視窗內，曾把 `html`、`body`、`.tactics-app` 與 `.screen-home` 一起限制為 `100dvh` 並隱藏溢位。當出戰隊伍較多時，主城內容超出視窗卻無法下拉，導致「進入戰鬥」按鈕被裁掉。

## 修正

- 固定視窗規則只留給戰鬥頁；`body.view-home` 恢復垂直捲動。
- 主城與戰前隊伍區使用內容自然高度，不再裁切第 7〜10 隻幻獸。
- 新增固定於畫面底部的「隊伍就緒／進入戰鬥」操作列，任何捲動位置都能出擊。
- 主城底部預留安全空間，操作列不會遮住隊伍卡或戰場規則。
- 手機版縮成單一大型出擊按鈕，並保留安全區距離。
- 新增回歸檢查，防止日後重新引入主城 `overflow:hidden`。
