# JOSE 幻獸戰棋：遊戲說明書

更新日期：2026-07-17（V0.11）

## 遊戲目標

指揮最多十隻幻獸組成的遠征隊，討伐每關 10〜30 隻的魔物大軍，依序攻略 4 張地圖、16 個關卡，
擊敗盤據各章節的魔物大軍與 4 隻章節首領，最終封印三界裂隙。

## 遊戲分為三個頁面

1. **主城**：功能格進入各系統——⚔️ 關卡（章節節點地圖）、🐉 幻獸編隊（1〜10 隻）、⬆️ 強化、📖 圖鑑、🎰 召喚、📋 每日任務；按「⚔️ 進入戰鬥」出擊當前關卡。
2. **戰鬥頁**：只有戰鬥需要的功能——30×30 大戰場（可拖曳地圖、點右上角小地圖跳轉視角，鏡頭會自動跟著行動的單位）、技能面板、自動戰鬥、速度與撤退。
3. **結算頁**：星級、統計與獎勵，可直接「下一關」「再次挑戰」或回主頁。

## 一場戰鬥的流程

1. **戰前部署**：點選我方幻獸，再點左下角藍色部署格自由擺位；按「⚔️ 開始戰鬥」。敵軍分小隊散布全圖，靠近 7 格才會驚動整隊。
2. **出手確認**：技能點擊目標會先顯示戰鬥預測（傷害／反擊／可擊破），再點一次才執行；點敵人可查看威脅範圍。
2. **我方回合**：每隻幻獸每回合可「移動一次＋行動一次」。點幻獸 → 藍格移動；右側面板選技能 → 點高亮目標施放。
3. **敵方回合**：我方全員行動完（或按「結束本回合」）後敵方行動。
4. 反覆進行直到一方全滅，或超過 40 回合判定撤退。

## 戰場元素

| 元素 | 效果 |
| --- | --- |
| 🌋／🌳／🪸／🔮 障礙物 | 不可通行，且會**遮蔽遠程與範圍技能的視線** |
| ♨ 熔岩格 | 火系站上去攻擊 +15%；非火系每回合受傷 |
| ♣ 森林格 | 森林系防禦 +12%、治療 +20% |
| ≈ 水域格 | 海洋系移動 +1、攻擊 +15% |
| 元素克制 | 火 → 森 → 海 → 火 ×1.25；光 ⇄ 暗 互剋 ×1.25 |
| 隊伍共鳴 | 三隻同元素 +12%，或三系互補 +8% |

| 狀態 | 圖示 | 效果 |

## 敵人圖鑑

- **12 種魔物小兵**（單階、不進化）：餘燼小鬼、灰燼魔犬、燼翼魔蝠、燼火妖靈（會幫敵方治療！）、荒疫魔豬、荊棘魔藤、劇毒魔螳、幽暗魔龜、濁潮魔星、深潮觸手、寒霜魔蟹、虛空魔鰻。
- **4 隻章節首領**：炎獄魔龍王（ember）、腐木巨像（verdant）、冰淵潮王（tide）、裂隙吞噬者（rift）。
  首領有專屬登場演出與畫面上方血條，體型大、招式帶範圍與控場，**免疫冰凍與位移**。

## 養成系統（「🧬 融合與技能樹」按鈕）

| 系統 | 消耗 | 效果 |
| --- | --- | --- |
| 進化（1→2→3 階） | 徽章🏅＋元素精華🔷 | 全能力 +12%／階，換立繪；3 階需先融合 1 次 |
| 融合（0→3 階） | 融合核心🧬＋精華🔷 | 永久全能力 +4%／階，並給 1 技能點 |
| 技能樹（每定位 3 節點） | 技能點 | 攻擊、防禦、射程、冷卻等專屬強化 |
| 遠征任務 | — | 完成戰鬥／控場／獵殺首領領取獎勵 |

資源來源：關卡首通獎勵最豐厚；菁英與首領關掉融合核心。

## 卡關了怎麼辦

1. **換隊伍**：45 隻幻獸全部可上場、一次出 6 隻——高稀有度幻獸基礎值更高；記得湊元素共鳴。
2. **利用克制**：對森林章帶火隊、對海洋章帶森林隊。
3. **帶治療者**：首領戰持久戰幾乎必備（治療型／輔助型）。
4. **控場**：冰凍高攻敵人、把敵人推離脆皮、拉近遠程敵人集火。
5. **回頭刷資源**：重複通關拿一半資源，把融合與技能樹補滿。
6. **觀戰自動戰鬥**：讓 AI 打給你看走位思路，也可調 1×/1.5×/2× 速度。
