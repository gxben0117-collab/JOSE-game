## 目前遊戲內容

- 主城包含戰役、編隊、強化、圖鑑、召喚、每日任務、幻獸之家、商店與背包。
- 戰役採 21×10 戰場、章節地圖、自由部署、手動／自動戰鬥、地形、元素、異常狀態與首領戰。
- 無限塔為守護塔防衛：每層 10 波，守護塔會在波次結束時治療隊伍、協助倒下幻獸復活；守護塔被擊破即挑戰失敗。
- 召喚採逐張揭示，顯示幻獸立繪與個別台詞，可使用右上角跳過。
- 戰場單位使用四方向待命、移動、攻擊圖集；投射物從施放者本體出發並在目標位置命中，速度會影響閃避機率。

## 每次修改的流程

1. 先依上表修改資料、程式或美術；不要直接手改由產生器管理的輸出。
2. 執行 `npm run lint` 與 `npm test`。
3. 需要確認戰鬥視覺時，啟動 `npm start`，以 `tactics.html?autotest=1` 做一場自動戰鬥檢查。
4. 以瀏覽器檢查桌機與 iPad 寬度，特別確認棋盤比例、技能投射物起點／終點與召喚逐張演出。
5. 僅提交本次相關檔案，推送 `master`；等待 GitHub Pages 完成後開啟正式網址驗證。

## 常用指令

```powershell
npm start        # 本機預覽：http://127.0.0.1:4173/
npm run lint     # JS 語法與 HTML 資產引用
npm test         # 資料、存檔、關卡與戰鬥回歸
npm run build    # 產出可部署的 dist/（需要打包交付時使用）
```

更細的模組說明請看 `docs/ARCHITECTURE.md`；新增資料、敵人、狀態與美術的操作細節請看 `docs/開發指南.md`；玩家玩法則看 `docs/遊戲說明書.md`。
