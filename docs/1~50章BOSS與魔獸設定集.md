# 《幻獸戰棋》1～50 章 Boss 與魔獸設定集

> 版本：v1.0｜用途：敵方資料庫、關卡配置、動作圖生成、美術審核與後續 11～50 章實裝的唯一敵軍參照。
>
> 依據：[世界觀與主線劇情設計基準](《幻獸戰棋》世界觀與主線劇情設計基準.txt) 與 `第11～50章 BOSS／關卡小兵／BOSS親衛隊設定稿`。第 1～10 章沿用目前遊戲 Canon 與既有敵方架構；第 11～50 章名稱、能力、數值階梯均以新增設定稿為準。

## 1. 實裝規格

| 分類 | 資料規格 | 棋盤／美術規格 | 關卡配置規格 |
|---|---|---|---|
| 小兵 `m01/m02` | `minion: true`、單階、N/R | S/M；1×1 | 普通關主要敵軍，依關卡配置 2～8 隻 |
| 親衛 `g01/g02` | `boss: false`、`roleLabel: 首領親衛`、SR/SSR | L 優先 2×2；特殊親衛可 M 1×1 | Boss 關各 1～2 隻；負責護盾、控場、治療或切後排 |
| 主 Boss `boss` | `boss: true`、UR/LR、獨立 AI | XL 3×3 或 4×4；篇章終章 XL／5×5 | 每個 Boss 關只允許 **1 隻主 Boss**；主 Boss 承擔階段、殘血與勝利判定 |
| 世界級 Boss | `phaseBoss: true`、多階段資料 | XXL；專用戰場與 UI | 第 50 章 Origin 不使用一般複製名冊 |

### Boss 關統一編成

`主 Boss ×1 + 親衛 G01 ×1 + 親衛 G02 ×1 + 對應小兵 ×2～6`。

禁止把同一關配置為多隻 4×4 Boss。親衛是「小 Boss／菁英守衛」，但程式 `boss` 旗標必須為 `false`；如此 Boss 來襲、殘血保存、Boss 血量百分比與討伐勝利皆只追蹤主 Boss。

### 現有 JavaScript 對應

```js
{
  id: 'c11_boss_scrap_crocodile', chapter: 11,
  name: '機關廢鐵巨鱷', faction: 'machine', unitType: 'boss',
  element: 'machine', rarity: 'UR', size: 4,
  stats: { health: 18000, power: 850, defense: 720, speed: 65 },
  move: 3, attackRange: 1, aiType: 'BOSS', boss: true,
  skills: [/* 基本攻擊、技能1、技能2 */],
  passives: [/* 主 Boss 專屬被動 */],
  evolution: [{ stage: 1, label: '首領', portrait: 'assets/enemies/c11_boss_scrap_crocodile.png' }]
}
```

目前引擎主元素為火／森／海／光／暗。新增的機械、雷霆、時空、混沌、龍魂、虛空應先保留為 `loreElement` 或擴充元素設定；戰鬥效果須落到既有燃燒、冰凍、毒、護盾、擊退、拉扯、治療、攻擊強化等可執行機制，避免資料有名詞但無效果。

## 2. 動作圖生成共通規格

- 每個單位：左／右／上／下的待機、移動、普攻；技能 1、技能 2 另做特效層或攻擊動作。
- 小兵：`1×1` 角色占畫面 78～88%，輪廓清楚；親衛：`2×2` 角色主體不得切邊；Boss：`3×3／4×4` 必須保留辨識度最高的頭、核心與武器。
- 同章兩種小兵應有清楚剪影差：前排重裝 vs 後排遠程／輔助。兩名親衛則應分工為「護主」與「施壓」。
- 生成提示最少包含：`faction / element glow / silhouette / weapon or organ / motion read / transparent background / no UI / no text`。
- 本文件的「動作與美術錨點」可直接轉為圖像提示詞；禁止生成帶文字、血條、邊框或卡牌框的角色圖。

## 11. 美術產製清單

- 第 1～49 章：每章 1 Boss + 2 小兵 + 2 親衛，合計 245 個單位規格（第 1～10 章既有資產可先比對、補繪缺口）。
- 第 50 章：1 個五階段 Origin + 4 種護衛／小兵，Origin 視為 5 個視覺階段資產。
- 生成優先序：`Boss 立繪 → 親衛立繪 → 小兵立繪 → 四方向待機／移動／攻擊 → 技能 VFX`。
- 每次生成後須在 `assets/enemies/<id>/` 下校驗透明背景、尺寸、方向表與 manifest；資料表最後才引用該 ID，避免戰場出現空單位。

## Canon 檢核

1. 第 11～20 章不可脫離「機械文明以效率／數據化解決世界」的衝突。
2. 第 21～30 章的天界是秩序與防災者，不寫成無理由的純惡。
3. 第 31～40 章的魔界是為生存而掠奪、正在逃離虛空，Boss 台詞與事件要保留這層反轉。
4. 第 41～50 章是多文明聯盟對抗歸零循環；虛空單位不應只是黑色怪物，必須有空間／規則被刪除的異常感。
5. 第 50 章結束第一部主線，但保留第 51 章「世界之外」擴充入口。
