# 幻獸養成與戰鬥系統完整方案

> 狀態：規劃完成，待依實作順序進入正式開發。
>
> 核心原則：先完成 45 隻幻獸的資料、定位、技能與戰鬥差異；正式像素美術與動作圖再依規格逐批替換，避免美術生產阻塞遊戲開發。

## 1. 幻獸資料結構

每隻幻獸都必須具備以下資料：

| 類別 | 必要欄位 |
| --- | --- |
| 基本 | 圖鑑編號、名稱、元素、稀有度、描述、所屬區域 |
| 定位 | 攻擊型、防禦型、輔助型、治療型、全能型、控制型 |
| 數值 | 生命、力量、魔力、防衛、速度、暴擊、效果命中、韌性 |
| 成長 | 等級、經驗、突破、星級、進化階段、進化素材 |
| 戰鬥 | 普攻、主動技能、被動技能、終結技、攻擊距離、站位 |
| 美術 | 幼體、成長體、最終型態、戰鬥動作、專屬特效、立繪 |
| 收集 | 解鎖方式、碎片來源、圖鑑獎勵 |

現有 45 隻幻獸需建立同一份標準資料表，不再只保留基礎生命、攻擊與防禦。

## 2. 戰鬥五大核心數值

| 數值 | 用途 |
| --- | --- |
| 生命 | 歸零即倒下，決定生存能力。 |
| 力量 | 影響近戰、物理技能、護盾破壞。 |
| 魔力 | 影響遠程法術、元素技能、治療與召喚。 |
| 防衛 | 減少物理傷害與部分衝擊效果。 |
| 速度 | 決定行動條、先後手、位移與閃避。 |

追加戰鬥參數：

- 暴擊：提高爆擊傷害機會。
- 效果命中：提高燃燒、冰凍、束縛等狀態命中率。
- 韌性：降低異常狀態持續時間與控制成功率。

## 3. 定位、攻擊距離與位移規則

| 攻擊類型 | 常見定位 | 戰鬥動作 |
| --- | --- | --- |
| 近戰 | 攻擊型、防禦型 | 跑到目標前方，攻擊命中後回位。 |
| 中距離 | 全能型、控制型 | 小幅前衝或原地施放，技能飛向目標。 |
| 遠程 | 法術型、治療型、輔助型 | 原地施放，投射物、光束或召喚物飛向目標。 |
| 範圍 | 龍、鳳凰、巨獸 | 蓄力後對敵方區域或全場釋放效果。 |
| 支援 | 治療型、輔助型 | 特效落在己方單體、前排或全隊。 |

每個技能都要有 `attackStyle`：`melee`、`ranged`、`support`、`area`。

只有 `melee` 觸發跑向目標的位移動畫；遠程攻擊不可錯誤地移動到敵人面前。

## 4. 戰鬥視覺回饋規格

每個行動最少包含以下步驟：

```text
蓄力 → 位移或投射 → 命中 → hit-stop → 受擊閃白 → 傷害字 → 狀態效果 → 回位
```

所有戰鬥行動都必須有特效。特效分為：

- 物理：斬擊、衝撞、震地、爪痕、碎石。
- 火焰：火球、火柱、爆炎、灼燒。
- 森林：藤蔓、葉刃、治療光、自然護盾。
- 海洋：水彈、水柱、冰刺、雷電、潮汐。
- 治療：上升綠光、回復數字、淨化粒子。
- 防禦：護盾、岩甲、減傷文字。
- 控制：暈眩、冰凍、束縛、緩速。

特效採兩層製作：通用特效庫供所有技能重複使用；幻獸專屬終結技提供角色辨識度。

## 5. 45 隻幻獸的技能規格

每隻幻獸至少有四個技能：

1. 普通攻擊：低冷卻，明確設定近戰或遠程。
2. 主動技能：代表該幻獸核心玩法。
3. 被動技能：凸顯其定位與隊伍價值。
4. 終結技：專屬 cut-in、強特效、較長冷卻。

範例：火狐。

| 技能 | 類型 | 規格 |
| --- | --- | --- |
| 鬼火 | 普攻 | 遠程藍焰投射物。 |
| 九尾亂舞 | 主動 | 中距離突進，多段斬擊。 |
| 靈敏 | 被動 | 提高速度與閃避。 |
| 蒼炎九尾 | 終結 | 敵方範圍爆發，配合 cut-in 與藍橙狐火。 |

範例：熔岩蟹。

| 技能 | 類型 | 規格 |
| --- | --- | --- |
| 蟹鉗 | 普攻 | 近戰跑向目標後夾擊。 |
| 熔岩護盾 | 主動 | 為自己或前排提供護盾。 |
| 硬殼 | 被動 | 提高防衛與韌性。 |
| 火山鎧甲 | 終結 | 嘲諷敵人、反傷並增加護甲。 |

## 6. 進化與最終型態

每隻幻獸預留三階：

```text
幼體 → 成長體 → 最終型態
```

進化不可只放大圖案；各階段需調整：

- 體型與輪廓。
- 元素紋路、角、翅膀、尾巴、裝甲或飾品。
- 技能特效的色彩、範圍與層次。
- 最終型態專屬終結技。

建議美術路徑：

```text
assets/pets/{pet_id}/
  stage_1/
  stage_2/
  stage_3/
  portrait/
  battle/
  vfx/
```

每階段預留：`idle`、`move`、`melee_attack` 或 `ranged_attack`、`skill`、`hurt`、`victory`、`defeat`、`evolution`。

## 7. 養成系統必要項目

- 等級與經驗。
- 突破與升星。
- 進化素材。
- 技能升級。
- 裝備或符文。
- 前排、中排、後排站位。
- 元素共鳴：三火爆發、三森林續航、三海洋控制。
- 圖鑑、收集獎勵、碎片召喚。
- 區域關卡、精英關、首領與每日素材本。

## 8. 實作順序

1. 建立 45 隻統一資料表：五大數值、定位、距離、技能、進化欄位。
2. 完成通用戰鬥引擎：行動條、近戰位移、遠程投射、受擊、狀態效果。
3. 完成攻擊、防禦、輔助、治療、全能、控制六種定位的邏輯。
4. 完成火系 10 隻的可玩垂直切片。
5. 建立通用特效庫。
6. 設計每隻幻獸的專屬終結技與進化視覺規格。
7. 決定正式像素繪圖或骨架動畫工作流後，依規格批量製作三階美術。
8. 擴充森林、海洋，完成 45 隻完整圖鑑。

## 9. 現階段結論

遊戲的優先順序應為：

```text
資料完整性 → 戰鬥差異 → 可玩循環 → 特效標準化 → 正式美術量產
```

不要先一次製作 45 隻完整動作圖。先讓每一隻在數值、定位、技能與戰鬥表現上真正不同，再以統一規格導入專門製圖流程。
