# 幻獸與魔獸四方向 1～12 幀動作圖規格

## 適用範圍

本規格適用於遊戲內全部 115 隻幻獸與 65 隻魔獸，共 180 個戰鬥單位。所有單位統一提供待命、移動、攻擊三種動作，以及下、右、上、左四個方向。具有獨立三階原畫的 65 隻幻獸，成長體與最終型必須另外建立專屬圖集，不得在戰場沿用幼體圖案。

## 圖集格式

- 單格尺寸：`112×112 px`，透明 RGBA。
- 圖集高度固定為 `1344 px`；寬度為 `112 × columns`，可從 `112 px` 到 `1344 px`。
- 欄數：取該圖集中所有動作的最大幀數，限制 1～12 欄。尚未升級的既有素材維持 6 欄。
- 列數：12 列，固定順序如下：
  1. `idle-down`
  2. `move-down`
  3. `attack-down`
  4. `idle-right`
  5. `move-right`
  6. `attack-right`
  7. `idle-up`
  8. `move-up`
  9. `attack-up`
  10. `idle-left`
  11. `move-left`
  12. `attack-left`

圖集檔名：

`assets/animations/directional/<unit_id>-motion-4dir-sheet.webp`

第 2、3 階進化圖集檔名：

`assets/animations/directional/<unit_id>-stage_<stage>-motion-4dir-sheet.webp`

散圖檔名：

`assets/animations/directional/frames/<unit_id>-<action>-<direction>-frame_01.png`

進化散圖在 `<unit_id>` 後加入 `-stage_2` 或 `-stage_3`。

影格編號從 `frame_01` 開始，依該動作實際幀數結束，最多到 `frame_12`。動作圖集目前使用 `idle`、`move`、`attack`；程式播放器同時支援 `cast`、`hit`、`victory`、`death`、`vfx` 與 `ultimate`。方向只允許 `down`、`right`、`up`、`left`。

## 1～12 幀資料規格

每個動作可獨立設定，不要求同一角色所有動作使用相同幀數：

```js
attack: {
  frameCount: 8,
  fps: 14,
  loop: false,
  hitFrame: 6
}
```

- `frameCount`：整數 1～12。超出範圍時 runtime 會安全限制在 1～12。
- `fps`：每秒播放幀數，允許 1～60。
- `loop`：待機、移動通常為 `true`；攻擊、受擊、死亡通常為 `false`。
- `hitFrame`：攻擊真正命中的幀，從 1 起算，必須位於該動作幀數內。
- `frames`：使用獨立散圖時可直接提供路徑陣列，程式會由陣列長度推導 `frameCount`。

角色本體新素材預設 8 幀；一般技能 VFX 預設 8 幀；重要技能可用 8～12 幀；Boss、最終型與必殺技演出採 12 幀。現有 6 幀素材完全相容，不會因播放器升級而被拉伸或缺幀。

runtime 設定集中在 `js/data/animation-config.js`，各圖集的實際欄數與動作設定登錄於 `assets/animations/directional/manifest.json`，瀏覽器同步資料為同目錄的 `manifest.js`。修改產圖設定後必須同時重建兩份 manifest。

## 既有六幀素材節奏

- 待命：基準站姿、吸氣、上提、最高點、回落、復位。
- 移動：前腳準備、重心上提、跨步、落地、後腳跟進、復位。
- 攻擊：預備、蓄力、最大後拉、出擊、回收、復位。

角色移動或攻擊時，圖案朝向必須與實際主方向一致；向右使用 `right`，向左使用 `left`，向上使用 `up`，向下使用 `down`。待命沿用角色最後面向。

## 不可裁切規則

- 每張散圖四周至少保留 3 px 完全透明安全邊距。
- 頭、耳朵、角、翅膀、尾巴、武器、火焰及攻擊特效都視為角色內容，不可碰到圖格外緣。
- 放大、旋轉或位移後必須重新限制內容範圍，不可依賴瀏覽器隱藏溢出。
- 產圖完成後必須執行 `python scripts/check-directional-frame-bounds.py`；任何一張不符合即視為建置失敗。

## 美術來源分級

- `authored-four-direction`：具有人工或 AI 核准的四方向參考原畫，直接依四方向原畫製作。
- `derived-from-approved-motion`：尚無四方向原畫時，以現有核准戰鬥圖為身份基準，保留右／左側面，並產生置中的下／上方向版本。之後補畫原生四方向原畫時可直接替換來源，檔名與遊戲介面不需變更。
- `approved-evolution-portrait`：以該階段核准進化原圖產生專屬四方向圖集，確保戰棋外觀與圖鑑目前進化階段一致。

來源類型、列順序與實際檔案統一登錄於：

`assets/animations/directional/manifest.json`

## 重建與驗證

```powershell
python scripts/build-four-direction-motion.py
python scripts/check-directional-frame-bounds.py
npm run lint
npm test
npm run build
npm run test:browser
```

產圖腳本只會清除並重建 `assets/animations/directional/frames/*.png` 與 `assets/animations/directional/*-motion-4dir-sheet.webp`，不會修改來源原畫或舊版左右動作圖集。
