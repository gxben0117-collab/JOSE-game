# 幻獸與魔獸四方向六幀動作圖規格

## 適用範圍

本規格適用於遊戲內全部 115 隻幻獸與 52 隻魔獸，共 167 個戰鬥單位。所有單位統一提供待命、移動、攻擊三種動作，以及下、右、上、左四個方向。

## 圖集格式

- 單格尺寸：`112×112 px`，透明 RGBA。
- 圖集尺寸：`672×1344 px`。
- 欄數：6 欄，代表同一動作的 6 個連續影格。
- 列數：12 列，固定順序如下：
  1. `idle-down`
  2. `move-down`
  3. `attack-down`
  4. `idle-right`
  5. `move-right`
  6. `attack-right`
  7. `idle-up`
  8. `move-up`
  9. `attack-up`
  10. `idle-left`
  11. `move-left`
  12. `attack-left`

圖集檔名：

`assets/animations/directional/<unit_id>-motion-4dir-sheet.webp`

散圖檔名：

`assets/animations/directional/frames/<unit_id>-<action>-<direction>-frame_01.png`

影格編號固定為 `frame_01` 到 `frame_06`。動作只允許 `idle`、`move`、`attack`；方向只允許 `down`、`right`、`up`、`left`。

## 六幀動作節奏

- 待命：基準站姿、吸氣、上提、最高點、回落、復位。
- 移動：前腳準備、重心上提、跨步、落地、後腳跟進、復位。
- 攻擊：預備、蓄力、最大後拉、出擊、回收、復位。

角色移動或攻擊時，圖案朝向必須與實際主方向一致；向右使用 `right`，向左使用 `left`，向上使用 `up`，向下使用 `down`。待命沿用角色最後面向。

## 不可裁切規則

- 每張散圖四周至少保留 3 px 完全透明安全邊距。
- 頭、耳朵、角、翅膀、尾巴、武器、火焰及攻擊特效都視為角色內容，不可碰到圖格外緣。
- 放大、旋轉或位移後必須重新限制內容範圍，不可依賴瀏覽器隱藏溢出。
- 產圖完成後必須執行 `python scripts/check-directional-frame-bounds.py`；任何一張不符合即視為建置失敗。

## 美術來源分級

- `authored-four-direction`：具有人工或 AI 核准的四方向參考原畫，直接依四方向原畫製作。
- `derived-from-approved-motion`：尚無四方向原畫時，以現有核准戰鬥圖為身份基準，保留右／左側面，並產生置中的下／上方向版本。之後補畫原生四方向原畫時可直接替換來源，檔名與遊戲介面不需變更。

來源類型、列順序與實際檔案統一登錄於：

`assets/animations/directional/manifest.json`

## 重建與驗證

```powershell
python scripts/build-four-direction-motion.py
python scripts/check-directional-frame-bounds.py
npm run lint
npm test
npm run build
npm run test:browser
```

產圖腳本只會清除並重建 `assets/animations/directional/frames/*.png` 與 `assets/animations/directional/*-motion-4dir-sheet.webp`，不會修改來源原畫或舊版左右動作圖集。
