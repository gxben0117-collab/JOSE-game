## 發布流程

1. 本機執行 `npm run lint` 與 `npm test`。
2. 開啟 `tactics.html`，確認本次調整的主要流程可用。
3. 只提交本次修改的檔案，推送到 `master`。
4. GitHub Pages 會發布靜態檔案；通常等待約一至數分鐘後重新整理正式網址。
5. 以無痕視窗或強制重新整理驗證新版，行動裝置請額外確認 iPad 的棋盤比例與操作。

## 使用者端快取排查

- 看到舊版：Windows 按 `Ctrl+F5`；macOS 按 `Cmd+Shift+R`；iPad Safari 關閉分頁後重新開啟。
- 若頁面載入異常：先確認網址是否為上方 `tactics.html`，再查看 GitHub Pages 的最新部署是否已完成。

正式產品不依賴伺服器 API、登入或資料庫；玩家進度保留在瀏覽器的 `localStorage`。
