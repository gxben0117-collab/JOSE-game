## CLAUBE 優先閱讀順序

1. 先讀本文件，了解目錄與命名規格。
2. 讀 `CLAUBE_匯入清單.md`，按現有遊戲資料結構建立 ID 與資源路徑。
3. 讀各分類的索引 `.md`，取得中文名、定位與效果建議。
4. 幻獸圖請使用 `01_幻獸/*.png`，不要使用 `_source_chroma/` 的製作中底圖。
5. UI 小圖可用已切割單圖；要重新切割時，可執行 `python 切割4x4圖集.py <圖集> <輸出資料夾> <前綴>`。

## 圖檔規格

- 幻獸：`1254×1254` RGBA PNG，透明背景，角色置中，適合縮圖、卡片立繪與戰鬥頭像。
- 地形／道具／技能圖集：`1254×1254`，4×4 排列；因 1254 無法被 4 整除，切割腳本會以座標比例分配邊界，避免遺失像素。
- 已切割單圖：邊長約 `313~315 px`，檔名依圖集由左至右、由上至下編號 `01~16`。
- 預覽：`05_預覽/` 僅供瀏覽，不建議當正式遊戲資源。

## 導入原則

- 建議遊戲內 ID 使用英文檔名主幹，例如 `emberhorn_beetle`、`fire_skill_01`。
- 中文顯示名稱、說明與效果數值放資料表，不要寫死在圖檔路徑。
- 幻獸首版可當卡片／圖鑑立繪；若要地圖行走動畫，需另做 sprite sheet 動畫幀。
- 地形第 1 列為基礎地板，第 2 列為功能格，第 3 列為障礙物，第 4 列為特殊建築／事件格。
- 技能圖示中的具體數值均為平衡建議，請 CLAUBE 接入現有傷害、冷卻、能量與狀態系統後再微調。
