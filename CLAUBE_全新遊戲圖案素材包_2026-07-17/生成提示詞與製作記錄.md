## 地形圖集提示詞模板

```text
Create one square 4x4 sprite atlas containing exactly 16 distinct environment tiles for a
polished 2D tactical fantasy monster game. High-resolution retro pixel art, crisp pixels,
consistent three-quarter top-down/isometric camera, same scale and lighting, clean equal grid,
no text, no labels, no numbers, no extra outer border. Each cell must contain one centered,
self-contained square tile with safe margins. Theme: {EMBER / VERDANT / TIDE / RIFT}.
Row 1: four base floor variations.
Row 2: four functional terrain/hazard tiles.
Row 3: four obstacles.
Row 4: bridge, event circle/crater, elemental shrine, boss platform.
```

四張 atlas 的細節分別使用熔岩／玄武岩、苔蘚／根系、濕石／珊瑚／冰、紫色星岩／光暗裂隙語彙。

## 後製與切割

- 幻獸使用 chroma key 去背，保留半透明邊緣以減少縮小時鋸齒。
- 圖集使用 `切割4x4圖集.py` 依比例座標切割，不假設圖寬一定可被 4 整除。
- `建立預覽圖.py` 會產生幻獸 contact sheet，並把各 atlas 轉成快速預覽 JPG。
- 若重跑影像生成，應保留新的原始圖並人工比較，不要無條件覆蓋已確認版本。
