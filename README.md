# JOSE：幻獸戰棋

純靜態 HTML、CSS、JavaScript 製作的單機戰棋 RPG，目標是達到上市手游的完成度。
正式入口只有「幻獸戰棋」；歷史 2D／3D 實驗檔案已封存於 `不需要的檔案/`。

## 目前內容（V0.12）

- **主城循環**：關卡、幻獸編隊、強化、圖鑑、召喚、每日任務、幻獸之家（駐守產出）、商店（每日限購）、背包；僅探索仍在開發（見 `docs/遊戲企劃藍圖.md`）。
- **我方陣營**：115 隻幻獸（45 原生 + 20 光暗 + 50 素材包新獸）、初始 4 隻；體型分 1×1 與 2×2（大型獸佔 4 格）。
- **星級經濟**：召喚重複＝複製體，升星消耗 2^(n-1) 隻同幻獸＋🪙 金幣（每星全能力 +10%，上限 9 星）；複製體可在商店賣掉。
- **無限塔**：層數無上限、每 5 層塔層首領、記錄歷史最高層。
- **敵方陣營**：12 種單階魔物小兵 + 4 隻章節首領，全部使用專屬魔化立繪（`assets/enemies/`）。
- **大地圖戰鬥**：固定 21 欄 × 10 列戰場；10 章各有普通、BOSS、HARD 專用大地圖。115 隻幻獸與 52 隻魔獸皆依待機／移動／攻擊方向切換左右動畫，並具備小地圖、BFS 路徑、障礙物視線遮蔽、反擊與冷卻。
- **控場狀態**：擊退、拉扯、冰凍、中毒、灼燒、護盾、攻擊強化，各有專屬特效與音效。
- **三畫面架構**：遠征準備、戰鬥、結算各自獨立頁面；戰鬥頁只放戰鬥功能鍵，棋盤最大化且格子尺寸固定一致。
- **大軍團戰**：我方 1〜10 隻左下角自由部署；敵方每關 10〜30 隻分小隊散布全圖（警戒圈 7 格），首領關斬首即勝。
- **戰前自由部署**：開戰前可在左側部署區自由擺放六隻幻獸的站位。
- **戰鬥演出**：爆擊系統、Boss 登場動畫、Boss 血條、擊殺演出、投射物、分級震動。
- **智能 AI**：移動 × 技能 × 目標聯合評估——擊殺偵測、集火殘血、元素克制、範圍最大化、控場時機、治療走位、地形趨避；敵我自動戰鬥共用同一套 AI。
- **戰役**：10 大章節 × 150 關——每章 10 小關＋魔王關（擊破開啟下一章）＋4 個 HARD 特別關；光暗互剋、10 隻章節首領。
- **養成**：三階融合、六定位技能樹、進化門檻、六項遠征任務（含控場與首領獵人）。
- **地形**：熔岩、森林、水域實際規則 + 火／森／海元素克制。
- Web Audio 即時合成音效；`localStorage` 本機存檔並自動遷移舊版進度。

## 執行

需求：Node.js 18+、Python 3（本機預覽伺服器）。遊戲本身沒有 production runtime dependency。

```powershell
npm install
npm start
```

瀏覽 `http://127.0.0.1:4173/`。

## 品質指令

```powershell
npm run lint   # JS 語法 + HTML 資產引用檢查
npm test       # 51 項資料、進度、關卡、引擎與 10 場內部遊玩回歸
npm run build  # 產出可部署的 dist/（只含執行期資產，約 78MB）
```

另有真實瀏覽器煙霧測試（全速自動打完一場並回報結果到網頁標題）：

```powershell
# 開發伺服器啟動後，用 headless 瀏覽器開啟：
# tactics.html?autotest=1                          → 第一關（另有 ?view=battle 直接看戰鬥頁版面）
# tactics.html?autotest=1&stage=rift-4&party=flame_emperor,forest_god,sea_emperor&boost=1
#   stage=關卡id  party=指定隊伍  boost=1 模擬滿養成
```

## 核心結構

- `tactics.html`：正式遊戲 UI、Boss 血條／登場容器與所有 modal。
- `js/tactics.js`：戰鬥控制器、視線、位移、狀態、AI 與 DOM 協調。
- `js/data/tactical-pets.js`：45 隻幻獸的戰棋數值、技能（含控場配置）。
- `js/data/tactical-enemies.js`：12 小兵 + 4 首領的敵方資料層。
- `js/data/tactical-content.js`：地圖、16 關、難度倍率、障礙物、掉落、任務與技能樹。
- `js/core/TacticalProgression.js`：存檔、解鎖、融合、進化與任務統計。
- `js/core/TacticalAudio.js`：Web Audio 音效（含爆擊／冰凍／中毒／Boss 音效）。
- `css/tactics-battle.css`：障礙物、部署區、狀態、Boss 與爆擊等新戰鬥樣式。
- `css/tactics-screens.css`：三畫面切換與大棋盤（固定 `--cell` 尺寸）版面。
- `scripts/`：建置、靜態檢查、回歸測試、遊玩模擬與敵人圖片生成（`generate-enemy-art.py`）。

詳細架構見 `docs/ARCHITECTURE.md`，開發流程見 `docs/開發指南.md`，玩法說明見 `docs/遊戲說明書.md`。
