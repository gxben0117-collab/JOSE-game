# 方案三備忘：JOSE 3D 寵物探索 Roguelite

> 狀態：只作為下一款新遊戲的前期企劃；不納入目前《JOSE：幻獸遠征》程式。

## 核心定位

一局 15～25 分鐘的 3D 寵物隊伍探險。玩家選擇三隻幻獸進入隨機路線，在戰鬥、事件、商店、休息與精英節點間抉擇，最終挑戰區域 Boss。局內祝福於探險結束後清除，寵物、進化、基地與圖鑑永久保留。

## 單局流程

1. 選擇三隻幻獸與一件探險遺物。
2. 從三條可見路線中選擇下一節點。
3. 戰鬥後從三個隨機祝福中選一個。
4. 精英戰取得改變流派的核心祝福。
5. 區域 Boss 依玩家累積的能力改變招式。
6. 勝利或失敗後結算基地資源、圖鑑與永久天賦。

## 局內流派

- 燃燒連鎖：燃燒死亡時向鄰近敵人擴散。
- 潮汐循環：技能消耗能量後返還部分能量。
- 荊棘守護：護盾破裂時反傷並治療最低血量隊友。
- 光暗轉換：光技能累積暗能量，暗技能消耗並爆發。
- 召喚夥伴：戰鬥中暫時召喚未上陣的圖鑑寵物。

## 永久系統

- 幻獸收集、星級、分支進化、技能樹與外觀染色。
- 訓練場、研究所、孵化室、料理屋及探險協會。
- 圖鑑提供橫向解鎖，不直接堆疊無限數值。
- 每隻幻獸有專屬事件與羈絆組合。

## 3D 製作原則

- 小型競技場與節點地圖，不製作昂貴的無縫開放世界。
- 沿用 GLB、低多邊形、共用骨架與材質換色管線。
- 每種體型準備 Idle、Move、Attack、Skill、Hit、Death、Victory。
- 首個 MVP：12 隻幻獸、3 個區域、45 個事件、3 個 Boss、60 個祝福。

## 與目前遊戲隔離

新遊戲應使用獨立目錄、獨立存檔 key、獨立平衡資料與版本號。可重用 3D 載入器、模型授權清單格式和 UI 元件，但不可直接修改目前遊戲存檔。
