## 🐛 常见问题排查

### 问题：效果没有显示

**检查清单：**
1. [ ] 清除浏览器缓存（Ctrl+Shift+Delete）
2. [ ] 硬刷新页面（Ctrl+F5）
3. [ ] 检查文件路径是否正确
4. [ ] 查看控制台错误信息

**解决方案：**
```html
<!-- 确认 index.html 中有这两行 -->
<link rel="stylesheet" href="css/emoji-enhance.css">
<script src="js/ui/EmojiEnhancer.js"></script>
```

### 问题：动画卡顿

**检查清单：**
1. [ ] 关闭其他占用资源的程序
2. [ ] 检查是否同时运行太多动画
3. [ ] 在 CSS 中增加动画周期时间

**解决方案：**
```css
/* 降低动画频率 */
#hud-gold {
  animation: gold-shimmer 5s ease-in-out infinite; /* 从3s改为5s */
}
```

### 问题：某些emoji没有增强

**检查清单：**
1. [ ] 元素是否有正确的类名
2. [ ] 元素是否在 DOM 加载后添加
3. [ ] 尝试手动触发增强

**解决方案：**
```javascript
// 在控制台执行
window.emojiEnhancer.enhanceAll();
```
