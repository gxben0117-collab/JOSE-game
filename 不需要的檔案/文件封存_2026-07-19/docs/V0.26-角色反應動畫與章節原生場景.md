# V0.26 角色反應動畫與章節原生場景

## 角色圖集

每個角色（幻獸、魔獸與進化階段）使用一張四方向 WebP 圖集。每個動作可設定 1 至 12 幀；目前角色本體統一為 8 幀。

動作順序為 `idle`、`move`、`attack`、`hit`、`victory`、`death`，每種動作皆有 `down`、`right`、`up`、`left` 四個方向，共 24 列。受擊、勝利與死亡列是實際角色逐幀影像，不再只依賴 CSS 位移、閃白或淡出。

執行 `python scripts/build-four-direction-motion.py` 會重建 production atlas 與 manifest。預設只輸出 WebP 圖集；若美術人員需要逐張 PNG 檢視或交付，執行：

```powershell
$env:JOSE_EXPORT_SOURCE_FRAMES = '1'
python scripts/build-four-direction-motion.py
```

## 十章原生場景

`scripts/generate-battle-assets.py` 以十個章節各自的場景構圖產生戰場底圖：翠林、霧沼、熔岩、古代遺跡、冰原、雷暴、潮汐海岸、浮空島、晶裂縫與虛空要塞。場景邊緣使用章節專屬地標，中央維持清楚的戰棋可讀區；Boss 與 Hard 關再從該章場景延伸出對應變體。

## GitHub Pages 體積

`scripts/build.mjs` 會排除 `assets/animations/directional/frames`、`sources` 與 `views`。這些屬於來源美術，不會進入 `dist`；遊戲只載入圖集與 manifest，因此不影響戰鬥動畫。
