# JOSE 幻獸戰棋：後續開發執行清單

更新日期：2026-07-15

## 目前已完成

- 戰棋可操作原型：六乘五棋盤、移動、近戰突進、遠攻、輔助、傷害與元素特效。
- 45 隻幻獸資料：定位、力量、魔力、防衛、速度、血量、技能與三階演化資料索引。
- 45 隻三階演化圖：皆已去背並存於 `assets/pets/<幻獸 ID>/evolution/evolution-sheet-v1.png`。
- 基本十場戰棋模擬、JavaScript 語法檢查、桌機與手機畫面檢查。

## 接續工作順序

### 1. 三階圖片切圖與資料接入

- 將每一張三欄演化圖切為：`stage_1.png`（幼體）、`stage_2.png`（成長體）、`stage_3.png`（最終型）。
- 保留原始去背圖與來源圖，不覆寫。
- 在 `js/data/tactical-pets.js` 改用實際切圖路徑。
- 驗收：45 隻 × 3 階，共 135 張透明圖皆可讀取、無色鍵殘留、沒有切邊。

### 2. 動作系統

每隻幻獸至少具備以下戰鬥狀態：

- 待機、警戒、移動、近戰攻擊、遠距施法、受擊、勝利、失敗／死亡。
- 近戰：移至目標相鄰格，命中後返回。
- 遠攻與輔助：停在原格施放。
- 共通品質條件：主體不可被上下切割；不可以位移到棋盤外；受擊須含閃白與短暫停格。

### 3. 專屬技能 VFX

- 每隻幻獸至少一個專屬主技能特效，另有普攻與受擊共通特效。
- 特效依元素與技能語意區分：火焰、森藤、海潮、冰晶、雷電、毒霧、治療、護盾、強化。
- 每個 VFX 需設定：施放位置、目標位置、持續時間、傷害／治療觸發時間、音效預留鍵。
- 驗收：45 個專屬 VFX 均能在戰棋實際施放，且不遮蔽 UI 或停留在棋盤上。

### 4. 戰棋正式化

- 三階進化選擇與立繪顯示。
- 顯示五維數值、定位、攻擊型態、射程、移動力與技能冷卻。
- 完整回合流程：速度排序、可移動格、可攻擊格、地形、勝敗與獎勵。
- 加入敵方 AI：優先目標、接近、攻擊、輔助與基本避險。

### 5. 全專案品質檢查

- 所有玩家可見 UI 使用繁體中文；首頁、遠征、戰棋、展示頁皆不可殘留英文介面。
- 連跑 10 場戰棋模擬，檢查無卡關、無無限回合、無生命值異常。
- 桌機（1440px）與手機（390px）檢查：棋盤、按鈕、文字、角色、動畫不可溢位或截斷。
- 靜態檢查：JavaScript 語法、資產 404、`git diff --check`。

### 6. 上架與關機順序

1. 本機完整驗收通過。
2. 部署至正式網站。
3. 驗證正式網址的首頁、遠征、戰棋及核心素材均可載入。
4. 向使用者回報正式網址與驗收結果。
5. 僅在上述全部完成後，依使用者授權執行電腦關機。

只有以下條件全部達成，才可標示「JOSE 幻獸戰棋完成」：

- 全繁體中文、十場模擬及桌機／手機 UI 驗收通過。
- 正式網站部署並完成線上驗證。
