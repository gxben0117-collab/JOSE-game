# V0.05｜戰役、養成與正式化

- 日期：2026-07-16
- 正式玩法仍只有「幻獸戰棋」，沒有恢復舊冒險或 3D 主線入口。
- 新增熔火裂谷、古木聖域、潮汐遺跡、三界裂隙共 4 張地圖與 16 關。
- 新增資料化目標、難度、首領、回合上限、星級與掉落。
- 新增戰術徽章、三系元素精華、融合核心、三階融合、六定位技能樹與遠征任務。
- 進化改為同時檢查徽章、元素精華；最終型另需至少融合一次。
- 地形不再只有外觀：熔岩灼傷、森林防禦／治療、水域海洋系機動與傷害已接入計算。
- 修正被動技能誤列、輔助傷害誤判、範圍技能只打一人與移動標記未驗證路徑等問題。
- 新增範圍命中、投射物、震屏、狀態圖示與 Web Audio 合成音效。
- 將存檔與養成拆為 `TacticalProgression`，音效拆為 `TacticalAudio`，關卡內容拆為 `tactical-content.js`。
- 回歸檢查擴充為 28 項，10 場內部遊玩包含終局關卡。
- 修正 390px mobile 的 Grid 最小寬度溢位，文件本身不再水平捲動。
