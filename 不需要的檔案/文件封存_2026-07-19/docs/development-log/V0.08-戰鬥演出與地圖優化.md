# V0.08 戰鬥演出與地圖優化（2026-07-17，package 0.7.1）

目標：戰鬥動畫特效再升級；戰場地圖去格子化。

## 1. 戰鬥動畫特效升級（tactics.js + tactics-battle.css）

分析原況：每次攻擊只有單一漸層光斑 + 傷害數字 + 直線投射物，缺乏層次。

新增：

| 特效 | 觸發 | 實作 |
| --- | --- | --- |
| 粒子爆散 `burst()` | 命中 8 顆／爆擊 14 顆／治療 7 顆上飄／死亡 14~26 顆炸開 | 隨機角度、距離、色相偏移、尺寸與延遲的 CSS 變數粒子 |
| 衝擊環 `impactRing()` | 近戰命中、爆擊、擊殺 | 擴散光圈 |
| 範圍技預示 `telegraphArea()` | 範圍技施放瞬間 | 半徑內格子閃爍標記（障礙格排除） |
| 終極技演出 `ultimateFlash()` | 施放終極技 | 棋盤暗角金光閃 |
| 投射物拖尾 | 遠程技能 | 依方向旋轉（--angle）＋彗星尾 |
| 傷害數字漂移 | 所有傷害 | 隨機橫向漂移上飄；爆擊獨立放大旋轉動畫 |
| 近戰蓄力突進 | 近戰技能 | dash keyframes 改為「後拉蓄力 → 撲擊 → 歸位」 |

## 2. 地圖去格子化（tactics-battle.css 覆寫層）

分析原況：每格粗邊框＋棋盤格交錯色＋重複木紋圖樣＋地形整格換色，網格感過重。

改為：

- 棋盤是**整片有機地表**：每章節專屬的多層 radial-gradient 大色斑 + 細顆粒 overlay（ember 熔岩棕紅／verdant 森綠／tide 海藍／rift 紫晶）。
- 格子本體透明，只留 `#ffffff09` 極淡格線。
- 地形改為**不規則圓角色斑**（nth-child 變化三種形狀＋旋轉），帶內暈光，不佔滿整格。
- 障礙物改為**立體岩塊**（圓角不規則、內外陰影、各章節配色）。
- 移動／攻擊／輔助／部署高亮維持清晰格子指示（圓角化）。

坑：格紋來源是 `.idle-arena .cell`（0,2,0）與 `.idle-arena .cell:nth-child(odd)`（0,3,0），
純 `.cell` 覆寫會被蓋掉——所有去格子化選擇器都要帶 `.idle-arena` 前綴與 nth-child 變體。
