# V0.14 戰鬥三欄框架與地圖置中

日期：2026-07-17

## 問題

戰鬥地圖本體靠在大型外框左側，地圖右方留下無用途空白；敵我資訊與操作按鈕則散落在外框之外，地圖與外框的視覺範圍不一致。

## 新版結構

- 整個戰鬥區改為單一置中的三欄戰術框架。
- 左欄：我方存活數、隊伍成員、血量、定位、佔格、目前選取、元素共鳴與關卡目標。
- 中欄：20×20 戰鬥地圖、小地圖、戰鬥訊息與地形圖例；地圖小於可視區時自動置中，大於可視區時保留拖曳與捲動。
- 右欄：敵軍剩餘數、首領生命、速度序列、選取單位資訊、技能與回合功能鍵。
- 三欄共用同一外框、背景、邊線與陰影，不再出現地圖外框和地圖本體各自對齊的情況。
- 外框依三欄實際內容高度收合，不再用 `flex:1` 拉到視窗底部而留下大塊下方空白。
- 980px 以下自動收斂為單欄：隱藏重複的左方名冊，保留中央戰場與完整右側指令區。

## 操作

- 點左側任一我方成員可選取並將鏡頭置中。
- 點棋盤敵方單位仍可置中並顯示威脅範圍。
- 行走與攻擊期間仍不自動追鏡。

## 驗證

- `npm run lint`
- `npm run test`
- `npm run build`
- 1920×1080 與 1600×900 Chrome 戰鬥畫面檢查
