# V0.24：中央戰鬥指令、部署預設與骷髏魔神

日期：2026-07-18

## 完成功能

- 戰前自由部署固定為靠左 3×10，並可儲存／清除目前隊伍的部署預設。
- 手動戰鬥點選我方幻獸後，在畫面中央開啟角色立繪、狀態、移動、待機與技能選單；選擇技能後回棋盤指定目標。
- `#` 地圖標註由禁行改為減速格：可通行、進入花費 2 點行動力、不遮蔽視線；無限塔不生成減速格。
- 圖鑑與戰鬥資訊補上被動能力的數值與實際效果說明。
- 新增骷髏兵、骷髏法師、骷髏騎士、骷髏士官長、骷髏王、骨龍、巫妖、巫妖王。
- 骷髏王、骨龍與巫妖可作為 4×4 菁英級 Boss；巫妖王為 5×5 魔神級 Boss。
- 29 隻 2×2 幻獸新增真正正面與背面原畫，四方向待機／移動／攻擊圖集不再旋轉側面圖。
- 全部 115 隻幻獸與 60 隻魔獸具備 6 幀 × 四方向 × 待機／移動／攻擊的戰鬥圖集。
- 已完成本回合行動的我方棋子與左側隊伍卡會同步降低亮度與彩度，未行動者保持正常光亮；新回合重置後自動恢復。

## 美術產線

- AI 原畫以五組 front/back atlas 製作，來源保存於 `assets/animations/directional/views/sources/`。
- `scripts/process-large-front-back-views.py` 負責去背、分格、清除相鄰格溢圖與 512×512 正規化。
- `scripts/build-four-direction-motion.py` 讀取 `views/<unit_id>-front.png` 與 `views/<unit_id>-back.png`，產生 112×112 六幀戰鬥圖集。

- `npm run test:browser`（桌面、行動版、HARD、Boss 與中央指令面板）
- `npm run build`
